# 🎨 이펙트 그림 폴더

예준이가 그린 **이펙트 그림**을 넣는 곳입니다. (캐릭터 그림은 `character/`)

## 넣는 방법

1. 그림을 찍어서 이 폴더에 넣기 (원본은 `.jpg`로 두어도 됩니다)
2. 배경을 지운 `이름.png`가 있어야 게임에서 씁니다
   - 만들기 도구의 **[🩹 흰 배경 지우기]** 로 미리보기가 가능하고,
     최종본은 캐릭터와 같은 배경제거 파이프라인으로 만듭니다

## 게임에서 쓰는 법

이펙트 설정에서 이모지 대신 `@이름` 을 쓰면 `effect/이름.png` 가 알갱이로 나옵니다.

예) `@불꽃` → `effect/불꽃.png`
