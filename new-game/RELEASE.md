## 1. 아빠가 하실 일

### 1-1. Apple Developer Program 가입
- https://developer.apple.com/programs/enroll/
- **개인(Individual)** 으로 가입하면 됩니다. 연 99달러(USD)이고, 매년 갱신해야 앱이 스토어에 남습니다.
- Apple ID에 **2단계 인증**이 켜져 있어야 합니다.
- 승인까지 보통 하루에서 이틀쯤 걸립니다.
- 개발자 이름(판매자 이름)이 스토어에 공개됩니다. 개인 가입이면 **아빠 실명**이 표시됩니다.

### 1-2. 맥 + Xcode
- iOS 앱 빌드와 업로드는 **macOS의 Xcode**에서만 할 수 있습니다. Xcode는 맥 App Store에서 무료로 받습니다.
- 추가로 필요한 것:
  - **Node.js** (LTS 버전): Capacitor 명령어 실행용
  - **CocoaPods** 또는 Swift Package Manager: Capacitor 버전에 따라 다르며, 프로젝트를 만들 때 안내합니다.
- 실제 아이폰이 있으면 테스트가 편합니다. 케이블로 연결하면 Xcode에서 바로 설치할 수 있습니다.

### 1-3. App Store Connect에 앱 만들기 (가입 승인 후)
- https://appstoreconnect.apple.com → **나의 앱 → ＋ → 신규 앱**
- 아래 값으로 만드시길 권합니다. 바꿔도 괜찮지만, 정하신 값을 Claude에게 알려 주세요.

| 항목 | 추천 값 |
|---|---|
| 이름 | 무지성 디펜스 |
| 기본 언어 | 한국어 (일본어 현지화 추가 가능, 게임 안에 일본판 있음) |
| 번들 ID | `com.kongpot9.musung` (Certificates, Identifiers & Profiles에서 먼저 등록) |
| SKU | `musung-defense` (아무 문자열이나 됨) |
| 카테고리 | 게임 → 전략 (보조: 캐주얼) |
| 가격 | 무료 · 앱 내 구입 없음 · 광고 없음 |

### 1-4. 심사 전에 채울 설문 (App Store Connect)
- **앱 개인정보 (App Privacy)**: 아래처럼 답하면 됩니다. 게임 코드 기준이에요.
  - 수집하는 것:
    - **사용자 ID**: 아이디/닉네임 (랭킹 표시)
    - **게임 플레이 내용**: 최고 웨이브, 세이브 데이터 (클라우드 저장)
  - 수집하지 않는 것: 이메일, 전화번호, 위치, 연락처, 광고 ID, 분석/추적 도구 (전부 사용 안 함)
  - 추적(Tracking): **아니요**
  - 비밀번호는 서버로 보내지 않습니다. 아이디+비밀번호를 SHA-256으로 섞은 열쇠만 사용합니다.
- **연령 등급**: 만화 같은 가벼운 폭력(몬스터를 공격) 정도라서 **9+** 가 나올 가능성이 높습니다.
  - ⚠️ "Kids(어린이) 카테고리"에는 넣지 않는 걸 권합니다. 넣으면 규칙이 훨씬 까다로워집니다.
- **심사용 계정 (App Review Information)**: ⚠️ **꼭 필요합니다.** 앱이 로그인해야 켜지는 구조라서, 심사원이 쓸 **테스트 아이디/비밀번호**를 하나 만들어 적어 주셔야 합니다.
  - 예: 아이디 `apptest`, 비밀번호는 아빠가 정해서 적기
- **개인정보 처리방침 URL**: Claude가 만들 페이지 주소를 넣습니다 (아래 2-2).
- **지원 URL**: 웹사이트 주소나 GitHub 주소면 충분합니다.

### 1-5. (선택) 구글 플레이
- 먼저 아이폰부터 하신다니 나중에 하셔도 됩니다. 참고로:
  - 25달러, 한 번만 냅니다.
  - **새 개인 계정은 비공개 테스트를 한 뒤에야 정식 출시**할 수 있습니다. 테스터 12명이 14일 동안 해야 하는데, 규정이 바뀔 수 있으니 가입할 때 확인해 주세요.
  - 같은 Capacitor 프로젝트로 안드로이드도 만들 수 있습니다. Android Studio가 필요하고, 맥이 아니어도 됩니다.

## 2. 게임 쪽에서 남은 일 (Claude 담당, 순서대로)

### 2-1. 로그인 + 계정 삭제를 웹사이트에 올리기 ✅
- ✅ 2026-11-26 웹사이트(main)에 올림. 이제 웹사이트도 **로그인해야 게임 시작**이 됩니다.
- 기존에 하던 사람은 회원가입하면 기기에 있던 기록이 그대로 계정으로 옮겨집니다.
- **심사용 테스트 계정**: 웹사이트에서 회원가입하면 그 계정이 앱에서도 그대로 됩니다 (같은 서버).
  - 아빠가 직접 만드세요 (예: 아이디 `apptest`). 비밀번호는 아빠가 정해서 App Store Connect '앱 심사 정보'에만 적습니다.

### 2-2. 개인정보 처리방침 페이지
- GitHub Pages에 `new-game/privacy.html`로 만듭니다.
- 주소 예정: `https://kongpot9.github.io/tower-defense/new-game/privacy.html`
- 담을 내용: 수집 항목(아이디, 게임 기록), 저장 위치(Firebase Realtime Database), 보관 기간, 삭제 방법(앱 안 ⚙️ 설정 → 계정 삭제), 문의처
- ⚠️ **문의 이메일**이 필요합니다. 공개해도 되는 주소를 하나 정해 주세요.

### 2-3. 앱 포장 (Capacitor)
- 저장소에 `app/` 폴더를 만들고 Capacitor iOS 프로젝트를 준비합니다.
- 게임 파일(`both.html` + `art/`)을 **앱 안에 통째로** 넣습니다. 그래서 인터넷이 없어도 켜집니다. 랭킹이랑 클라우드 저장만 인터넷을 씁니다.
- 지금은 글꼴을 Google Fonts에서 받아 오고 있어서, **글꼴 파일도 앱 안에 넣습니다.**
- 아빠가 맥에서 하실 일 (Claude가 정확한 명령어를 `app/README.md`에 적어 둠):
  1. `git clone` 받은 뒤 `cd app && npm install`
  2. `npx cap sync ios` → `npx cap open ios` (Xcode가 열림)
  3. Xcode에서 **Signing & Capabilities → Team**에 아빠 개발자 계정 선택
  4. 아이폰을 연결해서 한 번 실행해 보기
  5. **Product → Archive → Distribute App → App Store Connect** 로 업로드

### 2-4. 앱 아이콘
- 예준이가 다시 그리는 중입니다. 받으면 1024×1024와 Xcode에 필요한 크기로 맞춥니다.
- 애플 규칙상 아이콘은 **투명 배경이면 안 되고, 모서리도 직접 둥글게 하면 안 됩니다.** 애플이 알아서 둥글게 깎습니다.

### 2-5. 스크린샷 · 설명
- 아이폰 6.9인치(또는 6.7인치) 스크린샷을 3~5장 만듭니다. 게임 화면을 자동으로 캡처합니다.
- 설명 · 키워드 초안은 Claude가 쓰고, 예준이가 다듬습니다.
