## 예준이의 기획

**2026-11-18 — 처음 기획**
- 타워디펜스 777처럼 **돈**이 있지만 다르다
- **내 캐릭터 중 8마리를 골라** 전장에 나간다
- 적은 **한쪽에서 몰려온다** — 웨이브마다 썰어 버린다
- 적이 **100마리** 쌓이면 패배 · 캐주얼 게임
- 그림은 **예준이가 새로 그린다** (그 전까지는 임시 그림)

**2026-11-19 — 성장형 타워 디펜스로 변경**
- 처음엔 **전사만** 있다
- **웨이브가 끝나면** 캐릭터 소환 · 아군 버프템 · 터렛 같은 **선물**을 받으며 성장한다
- 선물은 **카드 3장 중 1장 고르기**
- 캐릭터 카드는 **내 덱 8마리**에서만 나온다 (전사는 덱에 항상 포함)
- 소환 버튼은 없어지고 **돈은 강화에만** 쓴다
- 터렛은 예준이가 **그림으로 알려 줄 예정** (그 전까지는 임시 터렛)

**2026-11-20 — 버프템은 또 고를수록 세진다**
- 처음엔 공격력 10% 카드를 또 고르면 **10% → 40% → 70% → 100%** (매번 30%씩 더)
- **모든 버프템**에 같은 규칙
- 같은 날 변경: **10% → 20% → 30%… 10%씩** 올라가게

**2026-11-20 — 플레이 화면 그림** (`art/src/field.jpg`)
- 위: **레벨 + 경험치 바** | **웨이브 수**
- 성 밖(하얀 곳)으로 적이 몰려오고, **성 안(회색 돌바닥)**에 아군이 선다. 성벽 위에는 아군을 놓지 않는다
- 예준이 그림을 그대로 전장 배경으로 사용 (`art/field.jpg`)
- 레벨: 적 1마리 = 경험치 1 (보스 10)
- **레벨이 오르면 특수 선물** (2026-11-20 예준이 결정) · 레벨 업은 **지금처럼 자주** (초반엔 거의 웨이브마다)

- 캐릭터를 누르면 **마크 인벤토리처럼 7칸**이 보여요 (칸을 누르면 설명)
- 들어가는 것: **웨이브 보상 버프템**(힘의 물약 · 번개 장갑 · 망원경 · 황금 주머니) + **레벨업 장비**(황금화살 등) + **상점 템**

## 🏅 레이팅 (2026-11-21 예준이 요청 · 재는 법은 Claude가 정함)

- **레이팅 = 최근 10판(일반 모드) 도달 웨이브 평균 × 20** — 한 번 운 좋게 높이 간 것보다 **꾸준한 실력**을 봄 (부활하고 이어서 한 건 한 판으로 침 · 던전은 안 침)
- 티어: 🥉 브론즈 0~399 · 🥈 실버 400~699 · 🥇 골드 700~999 · 💎 다이아 1000~1399 · 👑 마스터 1400+ (웨이브 평균 20 / 35 / 50 / 70)
- 랭킹 창에 탭 두 개: **🌍 전체** (모두 · 최고 웨이브 순) · **🏅 ○○ 랭킹** (나랑 같은 티어끼리 · 레이팅 순)
- 게임이 끝나면 "🏅 레이팅 640 → 693 · 🥈 실버"
- 🎯 **배치고사** (2026-11-21 예준이 결정): 시즌마다 **처음 5판**은 티어를 안 보여 줌 ("🎯 배치고사 3/5") → 5판째에 "🎉 배치 완료! 🥇 골드" · 배치 전엔 티어 랭킹에 안 들어감
- 🗓️ **시즌제** (2026-11-21 예준이 결정 · 길이는 Claude): **한 달 = 한 시즌** (2026년 11월 = 시즌 1, 12월 = 시즌 2 …)
  - 새 시즌: **시즌 랭킹 · 레이팅 · 배치고사가 새로 시작** (전적 바닥은 최고 레이팅의 70%만 남김 → 다시 80% 바닥)
  - **실제 기록은 안 지워짐**: 🌍 전체 랭킹 = 역대 최고 웨이브 + 그 기록을 세운 시즌 (예: "WAVE 100 · S1" = 시즌 1에 서버 최초 100웨이브)
  - 랭킹 탭 3개: 🌍 전체 (역대) · 🗓️ 시즌 N (이번 시즌 최고 웨이브) · 🏅 ○○ 랭킹 (이번 시즌 같은 티어끼리 레이팅 순)
- 🎁 **시즌 상위 티어 보상** (2026-11-21 예준이 결정 · 크리스탈 양은 Claude): 그 시즌에 **처음 도달하면 바로** 받음 (시즌마다 한 번씩)
  - 🥇 골드: 💎3,000 + 한정 핀 · 💎 다이아: 💎8,000 + 한정 핀 · 👑 마스터: 💎20,000 + 한정 핀 + **한정 스킨**
  - 📌 한정 핀: "S1💎"처럼 시즌 + 티어 · 랭킹에서 닉네임 옆에 제일 좋은 핀이 보임 · 랭킹 창에 "내 핀" 목록
  - 🎨 한정 스킨: 스킨 그림이 아직 없어서 **받을 권리만 저장** (`META.skinOwed`) → 스킨이 생기면 그때 지급
- 🚫 **일부러 져서 낮은 티어로 내려가기 막기** (2026-11-21 예준이 요청 · 숫자는 Claude): 그동안 전적도 봄 → 레이팅은 **지금까지 최고 레이팅의 80%** 와 **최고 웨이브 × 20 의 60%** 아래로 안 떨어짐 (예: 마스터 1400 찍은 사람은 아무리 져도 1120 = 다이아 아래로 안 감)
- 레이팅이 없던 예전 기록은 최고 웨이브 × 20으로 어림 · claude.ai 밖(Firebase)에서는 전체 랭킹만

### 👤 로그인 + ☁️ 클라우드 저장 (2026-11-23 예준이 요청 — 앱스토어 출시 준비)

- 웹사이트 · 앱은 **로그인해야 게임 가능** (켜면 로그인 화면부터) · claude.ai 버전은 claude 계정이 있어서 로그인 화면 없음
- **아이디 + 비밀번호** (나중에 구글 · 애플 로그인 추가 예정 — 예준이 결정)
  - 아이디 = **랭킹 닉네임** (로그인하면 닉네임 못 바꿈) · **한 사람만** 쓸 수 있음 (대소문자 같은 걸로 침)
  - 회원가입하면 **이 기기에서 하던 기록을 그대로** 내 계정에 저장
  - 로그인하면 **내 계정 기록을 불러옴** (다른 폰 · 앱 다시 깔았을 때)
- 기록이 바뀌면 **저절로 저장** (5초 뒤 · 앱을 내릴 때도) · 켤 때 서버 기록이 더 새것이면 그걸로 바꿈 (폰 두 개로 해도 안 꼬이게)
- ⚙️ 설정 → 👤 내 계정: 지금 저장 · 🚪 로그아웃 (서버에 저장한 다음 이 기기 기록을 지움 — 다른 사람이 같은 폰을 써도 안 섞이게 · 저장 못 하면 로그아웃 안 함)
- 🗑️ 계정 초기화 = 로그인은 그대로, **서버 기록도 처음으로**
- 안전: 아이디 + 비밀번호를 섞은 열쇠(SHA-256) 자리 `musung/save/{열쇠}`에 저장 → **비밀번호는 서버에 안 올라감** · 열쇠를 모르면 읽기 · 쓰기 다 못 함 · 아이디 목록 `musung/users/{아이디}`는 처음 가진 사람만 쓸 수 있음
- ⚠️ 비밀번호를 잊으면 찾을 방법이 없음 (아직 비밀번호 찾기 없음)
- ⚠️ **아빠가 Firebase 콘솔에 `firebase-rules.json` 규칙을 넣어야 작동** (`musung/users` · `musung/save` 추가) — 규칙을 넣기 전에 main에 올리면 아무도 가입을 못 해서 게임을 못 함!
