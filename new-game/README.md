## 숫자 바꾸기

`index.html` 안의 `BAL` (밸런스), `CHARS` (캐릭터), `BUFFS` (버프템), `TURRET` (터렛) 표만 바꾸면 게임이 바뀐다.
숫자 크기는 전사 데미지 200 기준 (적 체력 150부터, 웨이브마다 ×1.125).

봇 테스트 (강화를 완벽하게 하는 봇):
- 캐릭터 카드만 고르는 봇 → 웨이브 45
- 카드를 아무거나 고르는 봇 → 웨이브 82
- 캐릭터와 버프템을 섞어 고르는 쪽이 더 오래 버틴다
