# 🆕 구예준 STUDIO 신작 (이름 미정)

> 타워 디펜스 777 다음 게임. 목표: **앱스토어 출시**
> 기획: 구예준 · 개발: 아빠 & Claude

## 예준이의 기획 (2026-11-18)

- 타워디펜스 777처럼 **돈**이 있지만 다르다
- **내 캐릭터 중 8마리를 골라** 전장에 나간다
- 돈을 내면 그 8마리 중에서 **랜덤으로** 나온다
- 나온 캐릭터에 돈을 써서 **강화**할 수 있다
- 적은 **한쪽에서 몰려온다** — 웨이브마다 썰어 버린다
- 적이 **100마리** 쌓이면 패배
- 캐주얼 게임
- 그림은 **예준이가 새로 그린다** (그 전까지는 임시 그림)

## v0.1 시제품에 들어간 것

| 항목 | 내용 |
|---|---|
| 덱 편성 | 임시 캐릭터 12마리 중 8마리 선택 (저장됨) |
| 소환 | 덱 8마리 중 랜덤 1마리 · 비용 20G부터 소환할 때마다 +3G |
| 강화 | 아래 카드를 누르면 그 캐릭터 **전부** 공격력 ×1.3 · 비용 25G × 레벨 |
| 전장 | 칸 15개 (3줄 × 5칸) · 근거리는 앞줄, 원거리는 뒷줄에 자동 배치 |
| 이동·팔기 | 캐릭터를 누르고 빈 칸 → 이동 / 다른 캐릭터 → 자리 바꾸기 / 팔기 = 낸 돈의 절반 |
| 적 | 위에서 몰려와 빨간 방어선에 쌓임 · 10웨이브마다 보스 (적 10마리로 계산) |
| 패배 | 쌓인 적이 100마리 |
| 튜토리얼 | 첫 판에 3단계 설명 (777에서 31명이 한 판도 안 하고 떠난 교훈) |
