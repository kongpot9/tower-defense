## 예준이의 기획

**2026-11-18 — 처음 기획**

**2026-11-19 — 성장형 타워 디펜스로 변경**

- 터렛은 예준이가 **그림으로 알려 줄 예정** (그 전까지는 임시 터렛)

## 숫자 바꾸기
